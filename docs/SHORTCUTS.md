# Default Shortcuts

## Application Shortcuts
All app shortcuts use `⌃⇧` (Ctrl+Shift) as base modifier

| Shortcut | Application | Description |
|----------|-------------|-------------|
| ⌃⇧Z | Browser | Primary web browser |
| ⌃⇧A | Browser2 | Secondary browser |
| ⌃⇧C | Editor | Primary code editor |
| ⌃⇧V | Editor2 | Secondary editor |
| ⌃⇧T | Terminal | Terminal emulator |
| ⌃⇧O | Notes | Note-taking app |
| ⌃⇧M | Mail | Email client |
| ⌃⇧S | Spotify | Music player |
| ⌃⇧F | Finder | File manager |

## Window Management
All window shortcuts use `⌥` (Alt) as base modifier

| Shortcut | Action | Description |
|----------|--------|-------------|
| ⌥A | Left Half | Move window to left half |
| ⌥D | Right Half | Move window to right half |
| ⌥W | Top Half | Move window to top half |
| ⌥H | Bottom Half | Move window to bottom half |
| ⌥C | Center | Center window on screen |
| ⌥F | Full Screen | Maximize window |
| ⌥E | Next Window | Cycle to next window in app |
| ⌥Q | Previous Window | Cycle to previous window in app |

## General Utilities
Various modifier combinations

| Shortcut | Action | Description |
|----------|--------|-------------|
| ⌘⇧X | Close Finder Windows | Close all Finder windows |
| ⌘⇧W | Close Other Windows | Close other windows of current app |
| ⌘⇧Q | Close Other Apps | Close other applications |
| ⌃C | Copy Browser URL | Copy URL from active browser |
| ⌘⇧⌥L | Create Symlink | Create symbolic link |

| ⌘⇧L | Downloads | Open downloads folder |
| ⌘⇧F | Documents | Open documents folder |

| ⌘⇧O | Notes | Open notes folder |
